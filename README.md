# EPM XXV — Official Artist Site

A mobile-friendly static artist website for GitHub Pages. It uses plain HTML, CSS, and JavaScript with no build step.

## Included artwork

- `assets/images/epmxxv-logo.png` — transparent EPM XXV emblem for the site header, footer, gallery, and browser icon.
- `assets/images/epmxxv-portrait.jpg` — artist portrait used in the opening section and photo gallery.
- `assets/images/epmxxv-poster.jpg` — supplied poster artwork used in the release and gallery sections.

## Current site links and media

- The hero title is **LIFE & WISH**; its music button opens the Apple Music artist page.
- The video section features the channel's two most-viewed music videos at the time this version was prepared.
- Spotify, Apple Music, YouTube, and Instagram profile URLs are set in `site.js`.
- The contact button opens EPM XXV's Facebook link.
- To add a track, upload an MP3 under `assets/audio/` and set it as the audio source. The **Choose MP3** control previews a file only in the current visitor's browser.

## GitHub Pages

The website is designed to publish from the repository's `main` branch and root folder. Keep `index.html`, `style.css`, `site.js`, and the `assets/` folder together at the repository root. The project site address is:

`https://banyarsoan2008-coder.github.io/EPM-XXV/`
