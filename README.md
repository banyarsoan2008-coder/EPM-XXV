# EPM XXV — Official Artist Site

A mobile-friendly static artist website for GitHub Pages. It uses plain HTML, CSS, and JavaScript with no build step.

## Included artwork

- `assets/images/epmxxv-logo.jpg` — EPM XXV emblem for the site header, footer, and browser icon.
- `assets/images/epmxxv-portrait.jpg` — artist portrait used in the opening section and photo gallery.
- `assets/images/epmxxv-poster.jpg` — supplied poster artwork used in the release and gallery sections.

## Personalize the site

1. In `site.js`, replace the sample Spotify, Apple Music, YouTube, Instagram, and email destinations with your real links.
2. In `index.html`, replace `VIDEO_ID` and `VIDEO_ID_2` with the IDs from your YouTube video links and update their captions.
3. Replace the sample release title, artist bio, and contact email with your details.
4. To add a track, use a permanent audio file URL in the page or upload an MP3 under `assets/audio/` and set it as the audio source. The **Choose MP3** control previews a file only in the current visitor's browser.

## GitHub Pages

The website is designed to publish from the repository's `main` branch and root folder. Keep `index.html`, `style.css`, `site.js`, and the `assets/` folder together at the repository root. The project site address is:
